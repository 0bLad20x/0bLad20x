## Featured Project

### [Solana Token Observatory](https://github.com/0bLad20x/solana-token-observatory)

**Discover → observe → filter → investigate emerging Solana tokens in real time.**

<a href="https://github.com/0bLad20x/solana-token-observatory">
  <img src="https://raw.githubusercontent.com/0bLad20x/solana-token-observatory/main/docs/assets/observatory-universe.png" alt="Solana Token Observatory – Token Universe" width="100%">
</a>

New Solana tokens appear faster than a monitor can follow forever. The project turns that stream into a smaller, explainable working set: multi-source discovery feeds continuous observation, meaningful source-version changes are persisted in PostgreSQL, deterministic lifecycle rules reduce low-value tracking, and a read-only Observatory exposes the surviving state for bounded AI-assisted research.

**What it demonstrates:** multi-source ingestion · version-aware persistence · deterministic lifecycle automation · interactive data exploration · runtime telemetry · LLM tool calling and evidence-bound research · backend and frontend contract testing

→ **[Explore the project, architecture, live flow, and Analyst](https://github.com/0bLad20x/solana-token-observatory)**
