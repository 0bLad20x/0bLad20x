# Portfolio Integration

This is a curation step after a repository is READY. It is not another repository work package.

## Goal

Use only the projects that strengthen the overall portfolio story.

For each ready repository, ask:

- What distinct capability does this project prove?
- Does it complement the projects already featured?
- Can the project be summarized accurately in one or two sentences?
- Is there a strong visual worth reusing on the profile?
- Does it deserve a pin now, or is another project stronger?

Empty pin slots are fine.

## Profile

Keep the profile summary much shorter than the repository README. A featured project normally needs only:

- name + repository link;
- one clear value statement;
- optionally one strong maintained visual;
- a few technical signals when they materially help positioning.

Do not duplicate the project README on the profile.

## CV / applications

Reuse the same evidence but compress it further:

```text
problem / outcome
→ personal scope
→ relevant technical signals
→ repository link
```

A small stored project note with reviewed profile/CV wording can be useful, but it is optional. Do not create portfolio paperwork that is not actually reused.

## Done when

The repository either has a clear place in the current portfolio or is intentionally left unfeatured. Revisit the selection when stronger projects become ready.
